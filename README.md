# 台股入門 60 天

給完全沒買過股票的人：60 天從開戶、下第一筆零股，到看懂財報、線圖指標、美股和長期投資策略。
純 HTML／CSS／JavaScript，不用安裝任何東西，手機和 iPad 都好讀。

## 課程安排

| 週 | 主題 | 實戰日 |
| --- | --- | --- |
| 第 1 週 | 速成基礎＋開戶下單：股票與市值、交易規則與升降單位、看盤與五檔、大盤點數換算、下單方式、成本與交割 | 第 7 天：下第一筆零股 |
| 第 2 週 | 看懂公司：股利與殖利率、EPS 與本益比、月營收、三率、負債與現金流、產業性格 | 第 14 天：用檢查表分析一家公司 |
| 第 3 週 | 看懂價格：K 線和週期、均線、成交量和法人、MACD／KD／RSI／布林通道、新聞和目標價、美股時段 | 第 21 天：用看盤 App 追蹤一檔股票一週 |
| 第 4 週 | 長期投資：市場的脾氣、指數化投資、定期定額、資產配置和再平衡、利率景氣估值、風險控管 | 第 28 天：寫下長期投資計畫書 |
| 第 5 週 | 第一個月總結＋美股：投資心理、投資原則初版、本益比 TTM、晨星評等、複委託 vs 海外券商、美股的稅 | 第 35 天：用富途牛牛讀懂一檔股票 |
| 第 6 週 | 基本面進階：ROE、自由現金流、本益比區間、股價淨值比、成長率、讀法說會簡報 | 第 42 天：估一個合理價區間 |
| 第 7 週 | 技術面進階：支撐壓力、趨勢線、型態、背離、多週期、技術分析的限制 | 第 49 天：替持股畫出交易計畫 |
| 第 8 週 | 產業和總經：半導體、AI 供應鏈、通膨、美債殖利率和匯率、景氣循環、黑天鵝 | 第 56 天：寫一份市場週報 |
| 第 9 週 | 兩個月總結：債券和現金、長期目標、兩個月檢討、投資原則正式版 | 第 59 天：兩個月總檢討 |

第 36～60 課目前是預告（標「準備中」），課文裡的每個數字都要先查到來源和日期才會放上來。

每課固定結構：今天學什麼、白話解釋、台股實際案例（附資料日期和來源）、今日實戰、想一想、三行重點，最後一句「本課為教育用途，不構成買賣建議」。

案例數字是 2026 年 10 月下旬查證的，最新的股價資料是 2026-10-22 收盤（10/23 颱風、10/26 補假休市）。股價每天在變，網站上每個數字都標了日期。

## 網站功能

- **首頁「今天的課」**：從 2026-10-26 算第 1 天，每天（以台灣時間為準）自動換下一課。
- **進度格子**：60 格排成月曆，讀過的變紅（台股紅色代表漲）。
- **全部課程目錄**：九週分組，已讀的課蓋「已讀」紅印章。
- **看盤指南**（`guide.html`）：指標實驗室（用示意走勢點選 K 線，白話說明 MACD、KD、RSI、布林通道、均線、成交量），以及報價畫面、美股時段、分析師評級、看盤 App 的說明。
- **美股日報**（`trend.html`）：每個美股交易日的隔天早上更新。用真的日 K 解釋 SPY（代表標普 500）、TSLA、GOOG、NVDA、AAPL、COST 的趨勢，每檔有電腦自動算的體檢表和 Claude 的解讀與情境；「怎麼預測」教基準率、趨勢、價位、行事曆、情境和失效點；預測日記會在 5 或 20 個交易日後自動對答案，Claude 自己的練習預測也一起記分；最後是台股觀察名單（台積電、台達電、日月光投控、鴻海、智邦）。
- **上一課／下一課**：每課底部都有；外接鍵盤的 iPad 也可以按左右方向鍵。
- **實戰工具**（`tools.html`）：
  - 交易成本：手續費、交易稅、要付多少、損益兩平賣價。
  - 漲跌停價：依升降單位自動取到正確的刻度。
  - 停損與部位大小：依「每筆最多願意賠多少」算出最多可買幾股。
  - 我的交易紀錄：記錄每一筆買賣和理由，算平均成本、已實現和未實現損益，可以備份和還原。
- 已讀紀錄和交易紀錄都存在這台裝置的瀏覽器（localStorage），換裝置不會跟著走。

## 檔案

```
index.html        首頁（今天的課、進度）
lessons.html      全部課程目錄
lesson.html       課文頁，用 ?day=1 到 ?day=60 指定哪一課
tools.html        實戰工具
guide.html        看盤指南
trend.html        美股日報
css/style.css     樣式
js/lessons.js     60 課的內容和資料來源（要改課文就改這裡）
js/app.js         日期計算、已讀紀錄、課程畫面
js/tools.js       實戰工具的計算和交易紀錄
js/chart.js       指標實驗室（看盤指南用示意走勢，美股日報用真的日 K）和指標公式
js/trend-core.js  美股日報的計算：合併日 K、體檢表、支撐壓力、基準率、預測對答案
js/trend.js       美股日報的畫面和預測日記
data/us/          美股日 K、每天的日報和練習預測（格式和每天更新的步驟見 data/us/README.md）
tools/us-daily.js 每天更新美股日報用的指令（node），網站本身不會用到
tools/build-preview.py 把整個網站打包成一個 HTML 檔，給 claude.ai 的預覽用
```

### 預覽某一天

在網址後面加 `?today=YYYY-MM-DD`，可以假裝今天是那一天，例如 `index.html?today=2026-11-03`。

## 部署到 GitHub Pages

這個網站不需要建置，直接把整個資料夾當成靜態網站就可以。

1. 到 GitHub 上這個 repo 的 **Settings → Pages**。
2. **Build and deployment → Source** 選 **Deploy from a branch**。
3. **Branch** 選 `claude/festive-wright-5t36uk`，資料夾選 **/ (root)**，按 **Save**。
4. 等一兩分鐘，網址會是 `https://chloeyy135.github.io/stock-101/`。

根目錄的 `.nojekyll` 是告訴 GitHub Pages 不要用 Jekyll 處理，檔案原樣上線。

## 在自己電腦上看
