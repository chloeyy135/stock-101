每個日曆年各賺賠多少（第一年和最後一年可能不是完整的一年）。紅色是正的，綠色是負的，和台股看盤軟體一樣。

抱 N 年會怎樣

把歷史上每一天都當成進場日，各抱 1、3、5、10 年（買進持有），看最差、中間、最好的年化報酬，和有幾成的進場日最後是賺的。這是第 23 課「指數化投資」和第 22 課「市場的脾氣」最重要的一張表。

方法和限制

  • 資料。Yahoo Finance 的日線，價格經過「還原」：配息、分割都調整進去，所以報酬是含息總報酬。標「不含息」的標的是暫時借用美股日報的未還原日 K，報酬不含配息、不是含息總報酬，第一次自動更新後會換掉。
  • 成交。訊號用當天收盤算，隔天開盤才買賣，不會偷看到當天收盤。買進持有是第一天開盤買。
  • 成本。定期定額最後一天用市值計算，沒有扣賣出成本。
  • 指標。年化波動＝每日報酬標準差 × √252；夏普值＝日報酬平均 × 252 ÷ 年化波動（無風險利率當 0）；Calmar＝年化報酬 ÷ 最大回檔；XIRR 和 Excel 同一套算法。
  • 限制。只測了四種最常見的規則、沒有調參數，所以不會有「挑出最好看的那組」的問題；但也代表這不是在找最佳策略。不同標的歷史長度不同，不能直接互比。過去績效不代表未來；美股日報「怎麼預測」有講為什麼均線規則會「以前有效、後來失效」。
  • 進階模式。在瀏覽器裡用 js/backtest-engine.js 重新計算，和產生這頁數字的 Python 引擎對過同一組資料（tests/engine.test.js）。可以改成本、停損、碎股、定期定額投入法、投資組合再平衡，也有參數敏感度、walk-forward、成本敏感度和 bootstrap；估值回測因為沒有當時可得的財報資料，標示為尚不可用。
  • 程式。回測引擎在 tools/backtest/，有測試；設定在 config/backtest.json；每週由 GitHub Actions 重抓資料、重算、推回網站。
